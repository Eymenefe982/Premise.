NCBI search key none

NCBI asks every user to use their own key. The key is free, takes two minutes to get, and raises your PubMed rate limit from 3 requests/second to 10. Your key is stored encrypted.

  1. Open account.ncbi.nlm.nih.gov/settings
  2. Create an NCBI account or sign in with your Google account
  3. Scroll to the API Key Management section on the page
  4. Click Create an API Key
  5. Copy the generated key and paste it below
