Şifrenizi değiştirin

Geçici bir şifreyle giriş yaptınız. Devam etmeden önce aşağıdan kalıcı bir şifre belirleyin.

NCBI arama anahtarı yok

NCBI, her kullanıcının kendi anahtarını kullanmasını ister. Anahtar ücretsizdir, iki dakikada alınır ve PubMed hız sınırınızı saniyede 3 istekten 10 isteğe çıkarır. Anahtarınız şifrelenerek saklanır.

  1. account.ncbi.nlm.nih.gov/settings adresini açın
  2. NCBI hesabı oluşturun veya Google hesabınızla giriş yapın
  3. Sayfada API Key Management bölümüne inin
  4. Create an API Key düğmesine basın
  5. Üretilen anahtarı kopyalayıp aşağıya yapıştırın
